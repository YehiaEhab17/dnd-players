# dnd-players

Player-facing site and world notes for my D&D campaign (Obsidian-published).

A published Obsidian vault containing the player-visible parts of the campaign:
lore ("codex"), locations, and a map, plus the generated site assets
(`site-lib/`) for browsing it as a website.

## Structure

```
codex/        campaign lore pages (HTML)
locations/    location notes + map images
site-lib/     generated site (styles, scripts, search index, fonts)
```

## Viewing

Open the site through your Obsidian publish setup, or serve the `site-lib/`
output statically.
